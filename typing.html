The page draws its own keyboard because the system keyboard gives a web page neither touch positions nor touch-down times. Each keystroke records the touch (key, position on the keyboard, down and up times, force and contact size where the browser provides them) and both motion sensors from 50 ms before touch-down to 150 ms after, with the pre-tap level subtracted. If the next key lands before 150 ms the window is cut there and its true length is written. Features come from the first 100 ms so that most windows are complete: accelerometer and gyro peaks, rotation per push, which axes carry the response, the sign of the rotation about the dominant axis (which separates the two thumbs), and the pre-tap gyro level. At 59 samples a second 100 ms is six samples; native capture at 100 to 200 Hz would change this experiment's results more than any other on the index.
